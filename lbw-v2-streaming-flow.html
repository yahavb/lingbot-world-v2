Live video streaming

User → App → Prefill → Decoder

Four components. The user only talks to the app; the app only talks to prefill; prefill hands latent chunks to the decoder and relays its frames back. One session streams until the user stops it; the camera follows the user's last action.
One live session, step by step

User → prefill (DiT + T5) → decoder (VAE)

Start images and scene prompts are encoded once when the server starts (steps 2-3). Then each chunk: rank 0 reads the latest action, the DiT denoises the chunk with that camera, and sends the latent to the decoder; the DiT denoises the next chunk while the decoder streams this chunk's frames back. Timings measured through the web page on half a trn3 (TP4 × CP8): 0.58 s per DiT chunk, 17.3 fps, median 1.07 s from a press to its first frame at the browser.
